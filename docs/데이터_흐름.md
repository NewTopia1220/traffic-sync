# 데이터 흐름

## 1. V2X 신호 수집 흐름 (정기 폴링)

```
[V2X 공공 API (apis.data.go.kr/B551982/rti)]
        ↓ 30초 주기 (TrafficScheduler)
[V2xApiService.fetchSignalData()]
        ↓
[TrafficCacheService (인메모리 캐시)]
        ↓ broadcast
[TrafficWebSocketHandler]
        ↓ ws://localhost:8080/ws/traffic
[React useWebSocket hook]
        ↓ setState
[MapDashboard / MainDashboard 컴포넌트]
```

- 폴링 주기: `traffic.poll.interval-ms=30000`
- 초기 좌표: 잠실 (37.5133, 127.1002, 반경 1km)
- 캐시는 `Map<crsrdId, TrafficStatus>` 구조

## 2. 사용자 구역 선택 → 즉시 수집

```
[사용자 SeoulSvgMap에서 구 클릭]
        ↓ handleSelectGu(gu)
[POST /api/fetch-area?lat=..&lon=..&radius=2.5]
        ↓ MapController.fetchArea()
[cacheService.setCenter() → 폴링 좌표 변경]
[crossroadRepository.findWithinRadius() → DB 조회]
[v2xApiService.fetchSignalData(crossroads) → 실시간 호출]
        ↓
[cacheService.updateSignal() → 캐시 갱신]
[webSocketHandler.broadcast() → 프론트 전송]
```

## 3. AI 챗봇 흐름

```
[React AIChatBot 입력]
        ↓ POST /api/chat { question, crsrdId }
[Spring Boot ChatController.chat()]
        ↓ ChatService.ask()
[POST http://localhost:8001/api/agent/chat]
        ↓ Python agent_server.py
[LangGraph ReAct agent.ainvoke()]
        ↓ 도구 선택
[MCP stdio → mcp_server.py]
        ↓ HTTP 호출
[Spring Boot /api/signals 또는 /api/context/{id}]
        ↓ 응답
[Ollama qwen3:30b-a3b 추론]
        ↓ AIMessage.content
[extract_answer() → JSON 반환]
        ↓
[React 챗봇 패널에 표시]
```

### 챗봇 요청 본문 예시
```json
{
  "question": "지금 가장 막히는 교차로 3곳 알려줘",
  "crsrdId": null
}
```

### 응답 본문 예시
```json
{
  "answer": "1. 여의도역 5km/h\n2. 여의도굿모닝증권 7km/h\n3. 대방대림아파트 10km/h"
}
```

## 4. 구 단위 리포트 흐름 (현재 프론트에서 제거됨, 백엔드는 유지)

```
[POST /api/district/report { district: "송파구" }]
        ↓ MapController.districtReport()
[ChatService.districtReport()]
        ↓ POST http://localhost:8001/api/agent/district-report
[Python agent: get_district_traffic 도구 호출]
        ↓ MCP → /api/signals 필터링
[Ollama 리포트 생성]
        ↓ ReportResponse
```

## 5. WebSocket 연결/재연결 흐름

```
[App.jsx 최초 마운트]
        ↓ useWebSocket(VITE_WS_URL)
[new WebSocket('ws://localhost:8080/ws/traffic')]
        ↓ onmessage → setWsData()
[연결 끊김 감지 (onclose)]
        ↓ setTimeout 재시도 (자동)
[wsStatus: 'connecting' | 'connected' | 'disconnected']
```

- WebSocket 상태는 App 최상위에서 관리
- props로 MapDashboard / MainDashboard에 wsData, wsStatus 전달
- 모든 클라이언트에 동일 데이터 broadcast (구 단위 필터는 프론트에서)
