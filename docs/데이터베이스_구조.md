# 데이터베이스 구조

## DB 환경

### Oracle Autonomous Database
- **종류**: Oracle Cloud Autonomous Database (서버리스)
- **인증**: Wallet 기반 (TNS_ADMIN)
- **드라이버**: `ojdbc11 v23.4.0`
- **JDBC URL**: `application-secret.properties`에 보관

### Wallet 파일 위치
```
backend/src/main/resources/wallet/
├── cwallet.sso
├── ewallet.p12
├── keystore.jks
├── ojdbc.properties
├── sqlnet.ora
├── tnsnames.ora
├── truststore.jks
└── wallet.zip (옵션)
```

⚠️ wallet 파일들은 `.gitignore` 처리됨. 팀원 간 별도 공유.

### TNS_ADMIN 설정
- 보통 `application-secret.properties`에서:
  ```properties
  oracle.net.tns_admin=src/main/resources/wallet
  ```
- 또는 환경변수로:
  ```bash
  export TNS_ADMIN=/path/to/wallet
  ```

**테이블**: 신호 현시 (페이즈)

### 5. CctvEntity

## 레포지토리 (5개)

### CrossroadRepository
- `extends JpaRepository<CrossroadEntity, String>`
- **커스텀 메서드**: `findWithinRadius(double lat, double lon, double radiusKm)`
  - Haversine 공식 기반 반경 내 교차로 조회
  - `@Query`로 SQL 직접 작성

### SignalCrossroadRepository
- `extends JpaRepository<SignalCrossroadEntity, String>`
- 기본 CRUD

### SignalPhaseRepository
- `extends JpaRepository<SignalPhaseEntity, SignalPhaseId>`
- **커스텀**: `findByIdIntNo(String intNo)` - 특정 교차로 페이즈 전체
- **커스텀**: `findAllIntNos()` - 모든 교차로 번호 (DISTINCT) — `@Query` 사용

### SignalPlanRepository
- `extends JpaRepository<SignalPlanEntity, SignalPlanId>`
- **커스텀**: `findByIdIntNo(String intNo)`

### CctvRepository
- `extends JpaRepository<CctvEntity, String>`
- **커스텀**: 좌표 기반 거리 조회 (Haversine)

## Haversine 공식 (반경 검색)

```sql
SELECT * FROM crossroad
WHERE 6371 * acos(
  cos(radians(:lat)) * cos(radians(c.lat)) *
  cos(radians(c.lon) - radians(:lon)) +
  sin(radians(:lat)) * sin(radians(c.lat))
) <= :radiusKm
```

- 단위: 6371 = 지구 반지름 (km)
- 결과: `<= radiusKm` 내 행만 반환
