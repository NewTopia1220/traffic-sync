# AI 에이전트 구조

## 전체 흐름

```
[Spring Boot 8080]
       ↓ HTTP POST
[FastAPI agent_server.py :8001]
       ↓ ainvoke
[LangGraph create_react_agent]
       ↓ ReAct 루프
       ├── Tool Call → [MCP stdio]
       │                  ↓
       │              [mcp_server.py]
       │                  ↓ httpx
       │              [Spring Boot REST API]
       │                  ↓ JSON
       │              [Tool Result]
       └── LLM Inference → [Ollama :11434 qwen3:30b-a3b]
                ↓
       [최종 AIMessage]
```

## LangGraph ReAct 루프

ReAct = **Re**ason + **Act**

1. **Observe**: 사용자 질문 + 이전 도구 결과 관찰
2. **Think**: LLM이 다음 행동 결정 (도구 호출 vs 최종 응답)
3. **Act**: MCP 도구 호출 또는 최종 응답 생성
4. → 도구 결과를 다시 Observe (루프)

```python
# agent_server.py 핵심 코드
from langgraph.prebuilt import create_react_agent
from langchain_ollama import ChatOllama
from langchain_mcp_adapters.client import MultiServerMCPClient

llm = ChatOllama(model="qwen3:30b-a3b", base_url="http://localhost:11434",
                 temperature=0.3, num_predict=2048)

mcp_client = MultiServerMCPClient({
    "traffic": {
        "command": sys.executable,
        "args": ["mcp_server.py"],
        "transport": "stdio",
    }
})
tools = await mcp_client.get_tools()
agent = create_react_agent(llm, tools)

result = await agent.ainvoke({"messages": [{"role": "user", "content": prompt}]})
```

## MCP 서버 구조 (mcp_server.py)

stdio 방식으로 통신, `mcp` 패키지 사용.

### 노출 도구 6개

#### 1. `get_traffic_data(crossroad_id)`
- 특정 교차로 실시간 데이터 (신호·속도·날씨·위험도)
- 호출: `GET /api/context/{crsrdId}`

#### 2. `get_bottleneck_list()`
- 캐시 내 전체 신호 중 속도 낮은 TOP 10 (속도 0 제외)
- 호출: `GET /api/signals`
- 응답: `{ top10_bottlenecks: [...], total_count }`

#### 3. `search_crossroad_by_name(name)`
- 교차로 이름 부분 일치 검색
- 캐시 기반 (`/api/signals`)

#### 4. `get_district_traffic(district_name)`
- 자치구 단위 집계 (총 교차로, 평균 속도, 혼잡 TOP 3)
- 이름에 "강남" 등 포함 여부로 필터

#### 5. `set_signal_timing(crossroad_id, delay)`
- 신호 타이밍 조정 요청
- `POST /api/signal/adjust` (현재 미구현, 404 응답 처리)

#### 6. `send_alert(message)`
- 관리자 알림 (현재는 콘솔 로그)
- 향후 Slack/이메일 확장 가능

## 에이전트 서버 (agent_server.py)

### 포트: 8001
### 엔드포인트

#### `POST /api/agent/chat`
- 자유 질문 처리
- `crsrdId` 제공 시 해당 교차로 컨텍스트 자동 추가

#### `POST /api/agent/district-report`
- 자치구 리포트 생성 (`get_district_traffic` 호출)

#### `GET /health`
- 상태 확인: `{ "status": "ok", "model": "qwen3:30b-a3b", "mcp": "connected" }`

### 모델 설정
- `model="qwen3:30b-a3b"` - Qwen3 30B (MoE, Active 3B)
- `temperature=0.3` - 결정론적 응답
- `num_predict=2048` - 충분한 토큰 (512 미만은 도구 호출 실패)

### 응답 추출
```python
def extract_answer(result):
    for msg in reversed(result["messages"]):
        if not isinstance(msg, AIMessage):
            continue
        content = msg.content
        # list 형태 처리
        if isinstance(content, list):
            content = " ".join(item.get("text", "") for item in content)
        # <think> 태그 제거 (qwen3 thinking 모드)
        if "<think>" in content:
            content = content.split("</think>")[-1].strip()
        if content:
            return content
    return "응답을 생성할 수 없습니다."
```

## 모델: Qwen3 30B-A3B

- **종류**: MoE (Mixture of Experts) 모델
- **총 파라미터**: 30B
- **활성 파라미터**: 3B (추론 시 일부만 활성)
- **Thinking 모드**: `<think>...</think>` 블록으로 추론 과정 노출
- **Ollama 명령**: `ollama pull qwen3:30b-a3b`
