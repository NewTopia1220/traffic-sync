## 페이지 구조

### App.jsx
- **역할**: 최상위 컴포넌트, 페이지 전환 + 글로벌 상태 관리
- **라우팅 방식**: `useState`로 직접 페이지 전환 (React Router 7 설치되어 있지만 단순 useState 방식 사용)
- **WebSocket**: `useWebSocket` 훅으로 1개 연결만 유지, props로 하위에 전달

```jsx
function App() {
  const [page, setPage] = useState('main');
  const { wsData, setWsData, status, lastUpdate } = useWebSocket(VITE_WS_URL);

  if (page === 'main') return <MainDashboard onGoMap={...} wsData={wsData} />;
  if (page === 'map')  return <MapDashboard wsData={wsData} ... />;
  // ...
}
```

### MainDashboard.jsx (통합 대시보드)
- 서울 25개 자치구 SVG 지도
- 구 클릭 → V2X 데이터 즉시 수집 (`POST /api/fetch-area`)
- KPI 4종 (교차로 수, 위험 교차로, 평균 속도, 최고 위험도)
- 실시간 구간 속도 카드 (3개, 드롭다운 선택)
- 위험도 도넛 차트 + 8슬롯 관심 교차로
- 시간대별 교통량 예측 막대 차트
- **AI 리포트 패널은 제거됨** (모델 부하 문제)

### MapDashboard.jsx (실시간 지도)
- 카카오맵 기반 교차로 핀
- 교차로 클릭 → 좌측 하단 신호 패널 표시
- 우측 사이드바: 병목 목록 + 위험 목록
- 우측 하단: AI 챗봇 오버레이 (`AIChatBot`)
- 로드뷰 모달 / CCTV 모달

### SimulationDashboard.jsx (신호 시뮬레이션)
- 교차로 선택 → 신호 페이즈/플랜 표시
- 신호 주기 조정 → 시뮬레이션 결과 미리보기
- (향후) 3D 시각화

### CctvDashboard.jsx (CCTV 관제)
- HLS.js로 실시간 CCTV 스트림 재생
- UTIC iframe 임베드
- 위치별 카메라 그리드

## Hooks

### useWebSocket.js
- 단일 WebSocket 연결 관리
- 자동 재연결
- 상태: `connecting | connected | disconnected`
- 페이로드: `Map<crsrdId, TrafficStatus>` 형태 JSON

```jsx
const { wsData, setWsData, status, lastUpdate } = useWebSocket('ws://localhost:8080/ws/traffic');
```

### useChartJs.js
- Chart.js 인스턴스 동적 생성/제거 관리
- ref + useEffect 패턴

## 상태 관리

- **Redux 미사용**: `useState`, `useRef` 위주
- **글로벌 상태**: WebSocket 데이터는 App.jsx에서 보관 후 props 전달
- **로컬 상태**: 각 컴포넌트에서 useState로 관리
- **메모리 최적화**: sparkline 등 빈번 갱신 데이터는 `useRef`로 setState 우회

## 환경변수 (.env)

```
VITE_API_URL=http://localhost:8080
VITE_WS_URL=ws://localhost:8080/ws/traffic
VITE_KAKAO_APP_KEY=...
VITE_UTIC_KEY=...
VITE_VWORLD_API_KEY=...
```

⚠️ `VITE_API_URL`은 뒤에 `/` 없어야 함 (있으면 `//api/...` 더블슬래시)
