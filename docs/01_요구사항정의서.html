프로젝트 개요

1.1프로젝트 배경 및 목적

TrafficSync는 서울시 교차로의 실시간 V2X(Vehicle-to-Everything) 신호 데이터, 도로 속도 정보, 기상 데이터, 도로 위험도 정보를 통합하여 교통 관제 담당자 및 연구자에게 단일 통합 모니터링 플랫폼을 제공하는 시스템이다.

기존의 개별 공공 API 조회 방식은 데이터 수집·통합의 어려움과 실시간성 부족 문제가 있었다. TrafficSync는 다수의 공공 데이터를 자동으로 수집·가공·합산하고 WebSocket 기반 실시간 스트리밍으로 사용자에게 전달하며, LLM 기반 AI 에이전트가 자연어 질의에 응답하는 지능형 시스템을 목표로 한다.

핵심 목표: 공공 교통 데이터의 실시간 통합 수집 → 이상 탐지 및 병목 분석 → AI 기반 자연어 질의응답 → 신호 최적화 시뮬레이션

1.2시스템 범위

본 시스템의 범위는 다음과 같이 정의한다.

구분포함 범위제외 범위
지리적 범위 서울시 전 자치구 (구별 반경 2.5km 내 교차로) 경기도 및 수도권 외곽 지역
데이터 범위 V2X 신호, TOPIS 속도, KMA 날씨, 도로 위험도, T Data 신호·차량 데이터 대중교통 버스/지하철 운행 데이터
기능 범위 모니터링, 시각화, AI 분석, 신호 시뮬레이션, CCTV 관제, 이메일 알림 실제 신호 제어기 하드웨어 연동, 과금 시스템
사용자 범위 가입 인증된 내부 사용자 일반 시민 대상 공개 서비스

제약사항 및 가정

5.1기술적 제약사항

구분제약사항
LLM Ollama 로컬 실행 환경 필요. qwen3:30b-a3b 모델 다운로드(약 20GB) 필요. GPU 없는 환경에서 응답 지연 발생 가능.
V2X API V2X 신호 정보는 실제 V2X 장치가 설치된 교차로에만 데이터 존재. 모든 교차로에 신호 데이터가 있지 않을 수 있음.
T Data API T Data 운영계정 인증 후 사용 가능. 현재 개발 계정 보유, 운영 계정 신청 중. 운영 계정 승인 전까지 시뮬레이션 기능 제한.
UTIC CCTV 공인 IP 기반 화이트리스트 인증 방식. ISP 동적 IP 변경 시 UTIC 재등록 필요.
Oracle DB Oracle Autonomous DB (클라우드) 사용. 로컬 Wallet 파일 및 접속 정보 필요.
도로 위험도 API LineString 길이 최대 3,900자 제약. 긴 도로 구간은 분할 요청 필요.

5.2운영 환경 가정

구분가정 사항
네트워크 서버가 공공 API 서버(data.go.kr, openapi.seoul.go.kr 등)에 안정적으로 접근 가능한 인터넷 환경.
서버 스펙 Spring Boot, Python FastAPI, Ollama가 동일 호스트 또는 내부 네트워크에서 운영됨.
사용자 최종 사용자는 Chrome 또는 최신 브라우저를 사용하며 1280px 이상 해상도 환경.
데이터 신뢰성 공공 API는 일시적 장애·응답 지연이 발생할 수 있으며, 이 경우 직전 캐시 데이터를 사용.
주의: T Data API (신호제어기 신호 정보, 신호연결 Map, 교차로 Map, 차량 속도·위치) 는 현재 운영 계정 신청 중으로, 해당 기능(FR-SIM-01 ~ FR-SIM-07)은 운영 계정 승인 후 구현 완료 예정.
