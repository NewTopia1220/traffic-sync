# 프로젝트 개요

## 프로젝트 명칭
**실시간 V2X 기반 AI 교통 관제 시스템 (Traffic-Sync)**

## 핵심 목적
- V2X 공공 API로 교차로 신호 데이터를 30초 주기 폴링
- 로컬 AI 에이전트(Qwen3 30B)가 ReAct 루프로 자율 분석 및 권고
- 관제사 승인 후 신호 조정 (Human-in-the-loop)
- 폐쇄망 환경에서도 동작 가능한 완전 로컬 AI 아키텍처

## 개발 배경

### 기존 문제
- **Groq API 사용 시 문제**: 외부 API 의존, 비용 발생, 호출 제한, 데이터 외부 전송
- **공기업·관제망 요구사항**: 망분리 환경에서 외부 API 사용 불가

### 해결책
- **로컬 LLM 완전 교체**: Qwen3 30B-A3B를 Ollama로 로컬 실행
- **MCP(Model Context Protocol) 채택**: 표준 도구 인터페이스로 확장 용이
- **LangGraph ReAct 에이전트**: 판단·도구호출·관찰 루프

## 전체 시스템 구성

| 컴포넌트 | 포트 | 역할 |
|---|---|---|
| Spring Boot 백엔드 | 8080 | V2X 폴링, 캐시, WebSocket, REST |
| React 프론트엔드 | 5173 | 지도 시각화, 챗봇 UI |
| Python AI 에이전트 | 8001 | FastAPI + LangGraph |
| Ollama LLM | 11434 | qwen3:30b-a3b 추론 |
| Oracle Autonomous DB | (클라우드) | 교차로/CCTV/신호 메타데이터 |

## 주요 기능

### 구현 완료
- 실시간 V2X 신호 수집 (30초 폴링, `TrafficScheduler`)
- WebSocket 실시간 브로드캐스트 (`ws://localhost:8080/ws/traffic`)
- 카카오맵 기반 교차로 시각화 + 신호 상태 패널
- 서울 SVG 지도 + 25개 자치구 클릭 인터랙션
- 통합 AI 챗봇 (지도 페이지, 단건 질문)
- 신호 시뮬레이션 페이지 (`SimulationDashboard`)
- CCTV 관제 페이지 + HLS 스트림 (`CctvDashboard`)
- Oracle wallet 인증 + JPA 영속화
- MCP 도구 6개 (교차로 검색, 병목 조회, 신호 조정 등)

### 향후 계획 (스펙에만 존재)
- ChromaDB 기반 RAG (현재 미구현)
- bge-m3 임베딩 (현재 미구현)
- Three.js 3D 시뮬레이션 시각화 (현재 미구현)
- 신호 자동 조정 API (관제사 승인 기반)

## 포트폴리오 핵심 가치
- **완전 로컬 AI**: 외부 API 비용 0원, 데이터 외부 유출 없음
- **폐쇄망 보안 아키텍처 실증**: 공기업·관제망 환경 대응
- **MCP 표준 채택**: Anthropic의 표준 프로토콜 활용
- **융합 도메인**: 산업공학(교통) + AI(LLM) + 백엔드(Spring) + 프론트(React)

## 개발 환경
- macOS (M5 Pro, 48GB RAM)
- Java 17 (Amazon Corretto)
- Node.js 22+
- Python 3.14 (`ai-env` 가상환경)
- Ollama (Homebrew 설치)
- Git, IntelliJ IDEA, VS Code
