# 시뮬레이션 지식 (도메인)

> AI 에이전트가 신호 시뮬레이션을 수행할 때 참고하는 교통공학 지식 베이스.
> 이 문서는 향후 RAG 시스템에 적재될 예정.

## 1. 날씨별 교통 영향

| 날씨 | 속도 영향 | 사고 위험 | 제동 거리 |
|---|---|---|---|
| 맑음 | 기준값 | 1.0 (기준) | 1.0 (기준) |
| 비 | -20% | 1.3배 | 1.5배 |
| 눈 | -40% | 2.1배 | 2.5배 |
| 안개 | -30% | 1.8배 | 1.3배 |

### 적용 예시
- 평소 50km/h → 비 시 40km/h
- 평소 제동거리 15m → 눈 시 37.5m

## 2. 날씨·속도별 최적 신호 주기

| 조건 | 권고 신호 주기 |
|---|---|
| 맑음 + 고속(50km/h↑) | 30~40초 |
| 맑음 + 저속(30km/h↓) | 40~50초 |
| 비 + 저속 | 45~60초 (안전거리 확보) |
| 눈 + 저속 | 60초 이상 |
| 출퇴근 피크 | 90~120초 (긴 주기로 처리량 ↑) |
| 심야 | 60초 이하 (대기 시간 ↓) |

## 3. Webster 신호 최적화 공식

교통공학의 고전적 신호 최적화 공식:

```
Co = (1.5 × L + 5) / (1 - Y)
```

- **Co**: 최적 신호 주기 (초)
- **L**: 총 손실 시간 (초) — 신호 전환 시 차량이 출발하지 못하는 시간 (보통 4초/페이즈)
- **Y**: 총 포화도 — 각 현시의 교통량 / 포화 교통량의 합

### 예시 계산
- L = 12초 (3개 페이즈 × 4초)
- Y = 0.6 (60% 포화)
- → Co = (1.5 × 12 + 5) / (1 - 0.6) = 23 / 0.4 = **57.5초**

### 한계
- 정상상태 가정 (피크 시간엔 부정확)
- 좌회전/우회전 분리 미반영
- AI 에이전트는 Webster + 실시간 데이터 보정 조합 권장

## 4. 병목 판단 기준

다음 중 하나라도 만족 시 "병목 상태":

1. **평균 속도 15km/h 이하 지속** (10분 이상)
2. **대기 차량 급증 패턴**: 5분 평균 대비 200% 이상
3. **급감속 연속 감지**: V2X에서 5초 내 -10km/h 이상 감속 3회 이상
4. **신호 대기 시간 90초 초과**

### 혼잡 분류
| 평균 속도 | 분류 | 색상 |
|---|---|---|
| 40km/h 이상 | 원활 | 🟢 |
| 20~40km/h | 서행 | 🟠 |
| 20km/h 미만 | 혼잡 | 🔴 |

## 5. 한국 도로 기준

### 제한 속도
- 도심: 50km/h
- 스쿨존: 30km/h
- 자동차 전용도로: 80km/h
- 고속도로: 100~110km/h

### 신호 주기 권고 (도로교통법)
- 일반 교차로: 60~120초
- 보행자 신호 최소 시간: 보행거리 / 1.0m/s

### V2X 데이터 표준
- `protected-Movement-Allowed`: 보호 좌회전/직진 허용
- `permissive-Movement-Allowed`: 양보 좌회전 허용
- `stop-And-Remain`: 정지 (적색)
- `caution-Conflicting-Traffic`: 주의 (황색)

## 6. 교차로 위험도 점수 산출 (참고)

```
riskScore = w1 × (도로 구조 점수)
         + w2 × (사고 이력 점수)
         + w3 × (실시간 속도 점수)
         + w4 × (혼잡 점수)
```

- 0~100점 스케일
- 70점 이상: 위험
- 50~69점: 주의
- 50점 미만: 양호

## 7. 보행자 안전 고려

- 보행 신호 최소 시간: 4초 + (보행거리 / 1.0m/s)
- 노인·어린이 보호구역: 1.0m/s → 0.8m/s 적용
- 잔여 시간 표시는 카운트다운 형식 (디지털)

## 8. 신호 조정 시 유의사항

### 단방향 조정 (한 교차로만)
- 인접 교차로와 동기화 깨질 수 있음
- 5초 이내 미세 조정 권장

### 회랑 조정 (Green Wave)
- 연속된 교차로의 신호를 동기화
- 평균 속도 × 교차로 간 거리 = 신호 오프셋 계산
- 도로교통공단 도구로 사전 시뮬레이션 권장

## 9. 비상 상황 대응

| 상황 | 대응 |
|---|---|
| 화재/구급 | 전방 신호 전체 청색 (긴급차량 통과) |
| 사고 | 우회로 신호 주기 +20초 |
| 정전 | 점멸 신호 모드 (적색) |
| 시위/행사 | 수동 신호 모드 |

## 10. AI 에이전트가 권고할 때의 표현

좋은 권고: "비 + 저속 상태로, 현재 60초 주기를 75초로 +15초 연장 권고. 보행자 안전 확보 + 차량 처리량 안정."

나쁜 권고: "신호 늘려야 함."

→ **근거 + 수치 + 효과**를 함께 표현해야 관제사가 신뢰함.
