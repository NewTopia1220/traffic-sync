# 시뮬레이션 구조

## 핵심 개념

**관제 시스템의 의사결정 모델**:

| 데이터 | 출처 | 변경 가능 여부 |
|---|---|---|
| 날씨 | 기상청 / 자체 수집 | ❌ 읽기 전용 |
| 차량 평균 속도 | V2X / CCTV | ❌ 읽기 전용 |
| 신호 주기 | 관제사 입력 | ✅ 유일한 조정 변수 |

**목적**: 신호를 실제로 바꾸기 전에, AI가 "이 신호로 바꾸면 어떻게 될까?"를 미리 예측하여 관제사가 검토할 수 있게 함.

## 입력값

### 1. 날씨 (자동 수집)
- 맑음 / 비 / 눈
- 향후 기상청 단기예보 API 연동 예정

### 2. 차량 평균 속도 (자동 수집)
- V2X 데이터에서 추출 (현재는 더미 데이터)
- 교차로별 km/h 단위

### 3. 신호 주기 (관제사 입력)
- 초 단위
- `SignalPhaseEntity`의 페이즈 시간 조정
- 한국 도로교통법 권고 범위: 60~120초

## 시뮬레이션 흐름

```
1. [관제사 SimulationDashboard 페이지 진입]
        ↓
2. [교차로 선택 → SignalCrossroadEntity 조회]
        ↓
3. [현재 신호 주기 표시]
        ↓
4. [관제사가 신호 주기 조정 (예: 60초 → 75초)]
        ↓
5. [시뮬레이션 실행 요청]
        ↓
6. [에이전트가 현재 날씨·속도 데이터 조회 (MCP get_traffic_data)]
        ↓
7. [Ollama가 변경 결과 예측]
   - 평균 대기 시간 변화
   - 처리 차량 수 변화
   - 사고 위험도 변화
        ↓
8. [결과 표시 → 관제사 검토]
        ↓
9. [관제사 승인 시 실제 적용 (향후 구현)]
   - set_signal_timing MCP 도구 호출
   - DB SignalPlanEntity 업데이트
```

## 백엔드 구조

### SignalController
- `GET /api/signal/crossroads` — 시뮬레이션 가능 교차로 목록
- `GET /api/signal/crossroads/{intNo}` — 특정 교차로 신호 페이즈/플랜 상세

### SignalService
- `SignalCrossroadRepository` / `SignalPhaseRepository` / `SignalPlanRepository` 사용
- 신호 시뮬레이션 계산 로직

### 엔티티
- **SignalCrossroadEntity**: `intNo`(PK), `intNm`, `regionCd`, `xCoord`, `yCoord`
- **SignalPhaseEntity**: 신호 현시 (페이즈) - 복합 PK `SignalPhaseId`
- **SignalPlanEntity**: 신호 운영계획 - 복합 PK `SignalPlanId`

## 프론트엔드 구조

### SimulationDashboard.jsx
- 페이지 컴포넌트
- 교차로 선택 → 신호 주기 입력 → 시뮬레이션 결과 표시

### SignalSimPanel.jsx
- 시뮬레이션 패널 UI

### SimulationMapView.jsx
- 시뮬레이션 결과 시각화 (지도 기반)

## 3D 시각화 (향후 계획)

스펙에는 Three.js 3D 시각화가 포함되어 있으나, **현재 코드에 Three.js는 설치되어 있지 않음**.

향후 구현 시 예상 구조:
- 교차로 3D 모델 (`@react-three/fiber`)
- 차량 흐름 애니메이션
- 신호등 색상 변화
- 날씨 이펙트 (비, 눈 파티클)

## 에이전트 역할 (현재/향후)

### 현재 구현
- MCP 도구 `set_signal_timing(crossroad_id, delay)` 정의됨
- 실제 API (`/api/signal/adjust`)는 미구현 → 404 응답으로 처리

### 향후 확장
- 실시간 데이터 기반 최적 신호 주기 계산
- Webster 공식 적용
- 시뮬레이션 결과 자연어 해석
- 권고안 자동 생성

## 관련 외부 API

- **신호 시뮬레이션 API**: `apis.data.go.kr/1320000/CrossRoadInfoService/getCrossRoadInfoList`
- **신호 페이즈 API**: `apis.data.go.kr/1320000/CrossRoadInfoService/getCrossRoadInfoDetail`
- **신호 운영계획 API**: `apis.data.go.kr/1320000/PlanCrossRoadInfoService/getPlanCROPInfo`
- 지역 코드: `L01` (서울 일부)
