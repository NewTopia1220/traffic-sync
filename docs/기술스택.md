# 기술 스택

## 백엔드 (Spring Boot)

### 핵심
- **Spring Boot 3.5.12**
- **Java 17** (Amazon Corretto)
- **Maven** (`mvnw` wrapper 포함)

### 의존성 (pom.xml)
- `spring-boot-starter-web` — REST API
- `spring-boot-starter-websocket` — WebSocket
- `spring-boot-starter-webflux` — WebClient (비동기 외부 API 호출)
- `spring-boot-starter-data-jpa` — JPA / Hibernate
- `ojdbc11` (v23.4.0) — Oracle JDBC 드라이버
- `lombok` — `@Data`, `@Slf4j`, `@RequiredArgsConstructor`
- `jsoup` — HTML 파싱 (필요 시)
- `apache-poi` — Excel 파싱 (CCTV 메타 데이터)
- `jackson` — JSON 직렬화

### 인증/보안
- Oracle Autonomous DB Wallet 인증
- `TNS_ADMIN` 환경변수로 wallet 경로 지정
- 민감 정보는 `application-secret.properties`에 분리 (gitignore)

## 프론트엔드 (React)

### 핵심
- **React 19.2.5**
- **React DOM 19.2.5**
- **Vite 8.0.10** (번들러/개발 서버)

### 의존성 (package.json)
- `react-router 7.15.0` — 라우팅 (현재 App.jsx의 useState 전환과 병행)
- `react-bootstrap 2.10.10` + `bootstrap 5.3.8` — UI 컴포넌트
- `axios 1.16.0` — HTTP 클라이언트 (`fetch`와 혼용)
- `hls.js 1.6.16` — CCTV HLS 스트림 재생

### 외부 SDK (스크립트 로드)
- **Kakao Maps SDK** — 카카오 지도 (`VITE_KAKAO_APP_KEY`)

### 미설치 (스펙엔 있었으나 실제 없음)
- ~~Three.js~~ (3D 시뮬레이션 - 향후 추가 예정)
- ~~Chart.js~~ (직접 의존성 미설치, `useChartJs` 훅만 존재)

### 환경변수 (`.env`)
```
VITE_API_URL=http://localhost:8080
VITE_WS_URL=ws://localhost:8080/ws/traffic
VITE_KAKAO_APP_KEY=...
VITE_UTIC_KEY=...
VITE_VWORLD_API_KEY=...
```

## AI / 에이전트

- **Ollama** — 로컬 LLM 추론 서버 (포트 11434)
- **qwen3:30b-a3b** — 메인 LLM (MoE 30B/Active 3B)

### Python 라이브러리

- **httpx** — 비동기 HTTP 클라이언트

### 미사용 (스펙엔 있었으나 실제 없음)

## 인프라

### 런타임
- **macOS 14+** (Darwin 25.4)
- **Python 3.14** (가상환경 `ai-env`)
- **Node.js 22 LTS+**
- **Homebrew** (Ollama, Python 등 설치)

### 데이터베이스
- **Oracle Autonomous Database** (클라우드)
- JPA / Hibernate (`spring.jpa.hibernate.ddl-auto=update`)
- HikariCP 연결 풀
  - max pool size: 10
  - min idle: 3
  - idle timeout: 120초
  - max lifetime: 30분

### 개발 도구
- **IntelliJ IDEA** (Java 메인)
- **VS Code** (Python/React)
- **Git** (브랜치: `hi`)
- **Postman** / `curl` (API 테스트)

## 빌드 명령

### 백엔드
```bash
./mvnw clean install
./mvnw spring-boot:run
```

### 프론트엔드
```bash
npm install
npm run dev    # 개발
npm run build  # 프로덕션
```

### 에이전트
```bash
source ai-env/bin/activate
cd ai-agent
python agent_server.py
```
