# 서비스 설명

`backend/src/main/java/com/example/demo/service/` 의 8개 서비스 클래스 상세 설명.

## 1. V2xApiService `@Slf4j`
**역할**: V2X 공공 API 호출 + 응답 파싱

- 교차로 목록 조회: `apis.data.go.kr/B551982/rti/crsrd_map_info`
- 신호 정보 조회: `apis.data.go.kr/B551982/rti/tl_drct_info`
- 응답 JSON → `TrafficStatus` 객체로 변환
- `WebClient` 비동기 호출 (WebFlux)
- 디버그 로깅: `logging.level.com.example.demo.service.V2xApiService=DEBUG`

**핵심 메서드**
- `fetchSignalData(List<CrossroadInfo> crossroads)` → `Map<String, TrafficStatus>`

## 2. TrafficCacheService
**역할**: 인메모리 캐시 + 현재 중심 좌표 관리

- `ConcurrentHashMap<String, TrafficStatus>` 사용 (스레드 안전)
- 현재 폴링 중심 좌표 + 반경 보관 (`setCenter(lat, lon, radius)`)
- `TrafficScheduler`가 이 좌표를 기준으로 폴링

**핵심 메서드**
- `getAllSignals()` → 전체 캐시
- `updateSignal(String crsrdId, TrafficStatus status)`
- `getCenter()` → `(lat, lon, radius)`

## 3. ChatService `@Slf4j`
**역할**: Python AI 에이전트로 프록시

- **Groq API에서 로컬 에이전트로 완전 교체됨**
- `@Value("${agent.api.url:http://localhost:8001}")` 로 에이전트 URL 주입
- `WebClient`로 비동기 호출

**핵심 메서드**
- `ask(TrafficContext ctx, String question)` → `POST /api/agent/chat`
- `districtReport(String districtName)` → `POST /api/agent/district-report`

## 4. ContextService `@Slf4j`
**역할**: 교차로 ID → `TrafficContext` 빌드

- AI 에이전트가 도구로 호출 (`get_traffic_data`)
- 캐시 + DB + 외부 API 조합으로 컨텍스트 생성
- `TrafficContextProvider` 인터페이스로 실제/Stub 분기

## 5. ForecastService
**역할**: 24시간 교통량 예측 데이터 생성

- 현재는 시드 기반 더미 데이터 또는 캐시 패턴 기반
- 상행/하행 24개 점 배열 반환

## 6. SignalService
**역할**: 신호 시뮬레이션 데이터 조회/관리

- `SignalCrossroadEntity` / `SignalPhaseEntity` / `SignalPlanEntity` 조회
- `SignalCrossroadRepository` 등 사용

## 7. 데이터 초기화 서비스 3종 `@Slf4j`
### CrossroadDataInitService
- V2X API → DB(`CrossroadEntity`) 동기화
- 앱 시작 시 또는 수동 트리거

### SignalDataInitService
- 신호 페이즈/플랜 초기 로딩

### CctvDataInitService
- `cctv_with_Seoul.xlsx` 파싱 → DB(`CctvEntity`)
- Apache POI 사용

## 8. TrafficContextProvider 인터페이스
**역할**: 실제/더미 컨텍스트 전환

### 구현체
- **StubTrafficContextProvider**: `traffic.context.stub=true` 시 사용
  - 더미 데이터로 잠실 반경 1km 교차로 응답
- **RealTrafficContextProvider**: V2X API 실시간 호출

## 스케줄러 (별도)

### TrafficScheduler
- `@Scheduled(fixedRateString = "${traffic.poll.interval-ms}")`
- 30초 주기로 캐시 갱신 + WebSocket broadcast
- `@PostConstruct` 즉시 1회 실행

## WebSocket 핸들러 (별도)

### TrafficWebSocketHandler
- `WebSocketHandler` 구현체
- `Set<WebSocketSession>` 으로 연결된 세션 관리
- `broadcast(Map<String, TrafficStatus>)` 메서드로 전체 전송
- `WebSocketConfig`에서 `/ws/traffic` 경로에 매핑

## 의존 관계 다이어그램

```
                 ┌─────────────────┐
                 │ V2xApiService   │ ←─ 공공 API
                 └────────┬────────┘
                          ↓
                 ┌─────────────────┐
                 │ TrafficCache    │ ← TrafficScheduler (30초)
                 │   Service       │
                 └────────┬────────┘
                          ↓ broadcast
              ┌──────────────────────┐
              │ TrafficWebSocket     │ ──→ React
              │   Handler            │
              └──────────────────────┘

      ┌──────────────────────────┐
      │      ChatService          │ ──→ Python 8001
      └──────────────────────────┘
              ↑
              ContextService ←── TrafficContextProvider (Stub/Real)
                                        ↓
                              CrossroadRepository / DB
```
