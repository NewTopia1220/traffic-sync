# 실행 방법

## 사전 준비 체크리스트

### 필수 설치
- [ ] Java 17 (`java -version`)
- [ ] Node.js 22+ (`node -v`)
- [ ] Python 3.14 (`python3.14 --version`)
- [ ] Ollama (`ollama --version`)
- [ ] Git

### 환경 설정 파일
- [ ] `backend/src/main/resources/application-secret.properties` (V2X API 키 등)
- [ ] `backend/src/main/resources/wallet/` (Oracle wallet 파일들)
- [ ] `frontend/.env` (Kakao 키, API URL 등)
- [ ] `ai-env/` 가상환경 생성 완료

### Ollama 모델
```bash
ollama pull qwen3:30b-a3b
ollama list   # 확인
```

## 서버 실행 순서 (반드시 이 순서)

### [1단계] Ollama LLM 서버
```bash
ollama serve
```
- 주소: `http://localhost:11434`
- 안 켜면 → 에이전트가 LLM 못 찾고 startup 실패
- 백그라운드 실행 시: `nohup ollama serve > /tmp/ollama.log 2>&1 &`
- 상태 확인: `ollama ps` 또는 `curl http://localhost:11434/api/tags`

### [2단계] Python AI 에이전트
```bash
cd ~/traffic-sync-git
source ai-env/bin/activate
cd ai-agent
python agent_server.py
```
- 주소: `http://localhost:8001`
- 헬스 체크: `curl http://localhost:8001/health`
- 응답 예시: `{"status":"ok","model":"qwen3:30b-a3b","mcp":"connected"}`

### [3단계] Spring Boot 백엔드
```bash
cd ~/traffic-sync-git/backend
chmod +x mvnw   # 최초 1회
./mvnw spring-boot:run
```
- 주소: `http://localhost:8080`
- 헬스 체크: `curl http://localhost:8080/api/signals`
- 시작 시 자동으로 잠실 좌표로 V2X 폴링 시작

### [4단계] React 프론트엔드
```bash
cd ~/traffic-sync-git/frontend
npm install   # 최초 1회
npm run dev
```
- 주소: `http://localhost:5173`
- 자동으로 브라우저 열림

## 종료 방법

### 정상 종료
- 각 터미널에서 `Ctrl + C`

### 강제 종료
```bash
# Ollama
pkill -f ollama

# Python 에이전트
pkill -f agent_server.py

# Spring Boot (process 찾아서 kill)
lsof -i :8080
kill -9 [PID]

# React Vite
lsof -i :5173
kill -9 [PID]
```

## 모드 전환

### 더미 데이터 모드 (V2X API 없이 동작)
`backend/src/main/resources/application.properties`
```properties
traffic.context.stub=true
```
- 잠실 반경 1km 가짜 교차로 90개 정도가 보임
- 외부 API 호출 없음

### 실제 V2X 모드
```properties
traffic.context.stub=false
```
- V2X API 키가 `application-secret.properties`에 있어야 함

## 자주 발생하는 오류

### 1. `permission denied: ./mvnw`
```bash
chmod +x backend/mvnw
```

### 2. `address already in use` (포트 충돌)
```bash
lsof -i :8080   # 또는 :8001, :5173, :11434
kill -9 [PID]
```

### 3. `fetch failed` (에이전트 시작 시)
- Ollama가 안 켜져 있음 → `ollama serve` 먼저 실행

### 4. `externally-managed-environment` (Python pip)
```bash
python3.14 -m venv ai-env
source ai-env/bin/activate
pip install -r requirements.txt   # 가상환경 안에서
```

### 5. `cannot find symbol: class Data` (Java)
- IntelliJ에서 Lombok 플러그인 + Annotation Processing 활성화 필요
- File → 프로젝트 구조 → SDK → 17 Amazon Corretto 지정

### 6. 챗봇 응답 "응답을 생성할 수 없습니다"
- `num_predict`가 너무 작거나 (`agent_server.py`에서 2048 이상 권장)
- Ollama가 안 켜져 있거나
- MCP 도구가 빈 응답 반환

### 7. CORS 오류 (프론트)
- `frontend/.env`의 `VITE_API_URL=http://localhost:8080` (뒤에 `/` 없어야 함)
- 백엔드 `@CrossOrigin(origins = "http://localhost:5173")` 확인

### 8. `LangGraphDeprecatedSinceV10` 경고
- 무시 가능 (동작에 영향 없음)
- 향후 `from langchain.agents import create_agent`로 교체 예정

## 한 줄 실행 (개발 편의)

`tmux` 또는 4개 터미널 동시 실행 권장. 또는 백그라운드 스크립트:

```bash
# start-all.sh (예시)
#!/bin/bash
nohup ollama serve > /tmp/ollama.log 2>&1 &
sleep 3
cd ~/traffic-sync-git
source ai-env/bin/activate
cd ai-agent
nohup python agent_server.py > /tmp/agent.log 2>&1 &
sleep 3
cd ../backend
nohup ./mvnw spring-boot:run > /tmp/spring.log 2>&1 &
sleep 10
cd ../frontend
npm run dev
```
